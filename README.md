# Alhna_Events
## 📌 About the Project

**Ahlna Events** is an Android application designed to help users create, organize, and manage their special events in one place. The application provides a simple and user-friendly interface for managing celebrations, viewing upcoming events, organizing invitations, and keeping track of important dates.

The app is developed using **Kotlin and Jetpack Compose** in Android Studio, with a clean and modern design.

## ✨ Features

- 🔐 **Login Page** – User-friendly login interface.
- 📝 **Registration Page** – Interface for new users to register.
- 🏠 **Home Screen** – Welcoming dashboard with quick access to event management.
- 🎊 **Event Management** – Create and view events.
- 📅 **Calendar** – View and organize important dates.
- 💌 **Invitations** – Access and manage event invitations.
- 👤 **Profile Page** – User profile interface.
- 🎨 **Modern UI** – Attractive design with cream, forest green, and gold colors.
- 📱 **Android Application** – Designed for Android devices.

## 🚀 Getting Started

### Prerequisites

Install the following software:

- Android Studio
- Android SDK compatible with the project
- Git (optional, for cloning the repository)
- An Android emulator or Android device

### Installation

**Step 1: Clone the repository**

```bash
git clone https://github.com/poojithavakada7-hue/Alhna_Events.git
```

**Step 2: Open the project**

1. Open Android Studio.
2. Select **Open**.
3. Choose the cloned `Alhna_Events` project folder.
4. Wait for Gradle synchronization to complete.

**Step 3: Run the application**

1. Select an Android emulator or connect an Android device.
2. Click the **Run ▶** button in Android Studio.
3. Explore the application screens.
